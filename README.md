An entry for make.fun's "The Funniest Honest Appliance Error" bounty: a washing machine that finally tells the truth about the missing sock. One line of plain text, no more than 200 characters, written the way the machine itself would report it — flat, factual, and quietly fed up.

Running `main.py` produces the entry at `/output/entry.txt`:

> ERROR E17: Drain blocked by one sock. It is the one you swore the dryer ate. It has been in my filter since March.

## How to run

```sh
python3 main.py
```

The output directory can be changed with `MAKEFUN_OUTPUT_DIR`. The program checks the line first — length within 1–200 characters, a single line, and not blank — before writing it out.
